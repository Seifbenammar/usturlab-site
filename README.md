# usturlab-site

Site vitrine d'Usturlab OÜ, publié sur https://usturlab.eu

## Structure

```
index.html        solutions.html   about.html   contact.html    pages anglaises
fr/index.html     fr/solutions.html  fr/a-propos.html  fr/contact.html    pages françaises
assets/style.css  feuille de style unique, polices système, aucun appel externe
```

## Déploiement

Hébergement mutualisé OVHcloud, multisite `usturlab.eu` rattaché à l'espace
`tracksz.cluster021.hosting.ovh.net`, déploiement Git déclenché depuis ce dépôt.

## Règles de contenu

- Aucune donnée personnelle : ni nom de dirigeant, ni parcours individuel, ni pays
  d'intervention. L'identité du membre du conseil renvoie au registre du commerce estonien.
- Aucun cookie, aucune mesure d'audience, aucune police ni script chargés chez un tiers.
- Mentions légales conformes à la directive 2000/31/CE : dénomination, adresse, contact
  électronique, code de registre.
